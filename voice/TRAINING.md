# Mirai Native Voice 学習素材

自作音声モデル用の録音素材は Git に入れず、`data/voice_training/` に置きます。
`.gitignore` で `data/` 全体を除外しているため、録音やモデル重みでリポジトリが肥大化しません。

## metadata.csv

UTF-8 で、1行を次の形式にします。

```
relative/path.wav|その音声で実際に読んでいる文章
```

例:

```
wav/0001.wav|こんにちは、ミライです。
wav/0002.wav|今日はAIについて話します。
```

管理画面の「自作音声の学習素材チェック」を押すと、WAVの存在・サンプルレート・長さ・文章を確認し、
軽量な `manifest.jsonl` を生成します。WAV本体はコピーしません。

音声素材は、自分で収録した音声または学習・商用利用の権利が明確な素材だけを使ってください。
実在人物の声を無断で再現する用途は想定していません。
